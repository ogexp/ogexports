---
name: OG Exports Expo account separation
description: Keep OG Exports Expo builds separate from the existing OG Landmark Expo account and project.
---

OG Exports uses a separate Expo account/project from OG Landmark. The existing OG Landmark Expo project is not the OG Exports project; use only the account and project details the user provides for OG Exports.

**Why:** The user stated OG Landmark's Expo project is already available, while OG Exports has a different Expo account.

**How to apply:** Before any OG Exports build or account link, verify the OG Exports owner and project ID. Never reuse OG Landmark project identifiers or credentials.
