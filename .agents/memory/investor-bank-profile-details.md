Investor users should be able to enter bank details and save them directly to their investor profile without uploading a bank statement or cancelled cheque. Keep bank account identifiers masked in list views.

**Why:** The user asked for bank details to be saved to the profile without a bank proof upload.

**How to apply:** Use the investor profile update flow for bank details. Do not change withdrawal verification or eligibility rules unless the user explicitly asks.
