---
name: Mobile navigation motion
description: Investor app bottom-tab behavior during scrolling and reduced-motion preferences.
---

Hide the investor app's bottom tab bar while the user scrolls deeper into a page; reveal it on upward return, any screen tap, or shortly after scrolling stops. Preserve five-tab navigation and respect reduced-motion settings.

**Why:** The user explicitly requested a cleaner, more professional screen that gives content more room while scrolling and restores navigation on interaction or pause.

**How to apply:** Keep the behavior consistent across Dashboard, Opportunities, Portfolio, Wallet, and Profile. Preserve native iOS tabs when possible; keep tab controls reachable and avoid motion that delays user actions.
