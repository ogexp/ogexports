---
name: Investor mobile language scope
description: The investor mobile app should expose English as its only selectable interface language.
---

Keep English as the only selectable interface language in the OG Exports investor mobile app. Normalize legacy Urdu and Arabic preference values to English; retain translation resources unless their removal is explicitly requested.

**Why:** The user explicitly chose an English-only language selector for the mobile app.

**How to apply:** Keep Urdu and Arabic out of mobile profile/settings controls and ensure previously saved language preferences resolve to English. Do not extend this change to the website or admin language settings without a separate request.
