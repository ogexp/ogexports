OG EXPORTS — PREMIUM MOTION, ANIMATION & INTERACTION SYSTEM

Upgrade the existing OG Exports Investment Mobile App with a complete, modern, luxury-grade Motion & Animation System.

The app is an investment platform focused on Import/Export Container Investment Opportunities.

Do NOT make the animations childish, flashy, gaming-style, or excessive.

The desired visual direction is:

Luxury + Premium + Professional + Modern Fintech + International Trade + Trust + Precision

Think of the interaction quality of a premium fintech/investment platform, combined with the corporate identity of a global trading/export company.

The animation system must feel:

* Smooth
* Fast
* Elegant
* Sophisticated
* Minimal
* Responsive
* Trustworthy
* Expensive/premium
* Purposeful

Every animation must communicate an action, state, hierarchy, confirmation, transition, or progress.

120–180ms

180–250ms

250–350ms

250–400ms

400–700ms

600–1000ms maximum

Animations must be performance optimized.

* Transform
* Opacity
* Native/optimized animations
* GPU-friendly transitions where applicable

* Lag
* Battery drain
* Slow scrolling
* Delayed interactions

Animations must never block critical user actions.

“Processing…”

“Completed”

“Failed”

42. FINANCIAL TRUST PRINCIPLE

Because this is an investment application:

Animation must NEVER create misleading financial impressions.

Do not use:

* Guaranteed profit animations
* Fake profit increases
* Artificial earnings counters
* Misleading celebration
* Fake transaction confirmations

All financial numbers must come from real application data.

Use animation to improve clarity and confidence—not to manipulate the user.
